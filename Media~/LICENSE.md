# KawaPlayer 素材ライセンス 1.0

2026-10-12 制定

KawaPlayer の素材（下の「対象」）を使うときの条件です。

- **著作権フリーではありません。**
- **README の「利用規約」とは別です:** README の「利用規約」は KawaPlayer のコードとパッケージの条件で、素材には適用されません。

## 対象

- `Media~/` にあるロゴとポスター
- パッケージの中のロゴ（`Assets/Images/kawaplayer-logo.png`）

## 利用条件

○ はできること、× はできないことです。

| 項目 | 可否 | 補足 |
| --- | :---: | --- |
| 個人による利用 | ○ | |
| 法人・団体による利用 | ○ | |
| KawaPlayer を置いたワールドへの掲示 | ○ | |
| KawaPlayer を使ったワールド・アセットへの同梱（無償） | ○ | |
| KawaPlayer を使ったワールド・アセットへの同梱（販売） | ○ | クレジットが必要です（下の「クレジット」） |
| KawaPlayer を紹介する記事・動画・配信・SNS | ○ | 収益化しているものも含みます |
| KawaPlayer を紹介する印刷物 | ○ | |
| 改変 | × | 下の「改変に当たらないもの」はできます |
| 素材だけの再配布（素材配布サイトへの転載など） | × | |
| 素材そのものの販売、グッズにすること | × | |
| 自作発言（自分が作ったと言うこと） | × | |
| KawaPlayer が公認・提携していると誤解させる使い方 | × | |
| KawaPlayer 以外のものを紹介するための使用 | × | |
| 法令・公序良俗・VRChat の規約に反する場での使用 | × | |
| KawaPlayer や権利者の評判を傷つける使い方 | × | |

## 改変に当たらないもの

次の扱いは改変に当たらないので、自由にできます。

- 大きさを変える
- 画像の形式を変える
- Unity に読み込んだときに圧縮する
- ポスターの余白を切り抜く
- 好きな背景や、動画の画面の中に置く

次は改変です。

- ロゴの形・色・縦横比を変えること
- ほかの絵や文字を重ねること
- ポスターの文や画面を書き換えること

ロゴの色は、白・黒・グラデーションの 3 種類から選んでください。

## クレジット

- **販売するとき:** 販売するワールドやアセットに同梱するときは、商品ページか説明書に「KawaPlayer の素材を含む」と書いてください。
- **それ以外:** クレジットは任意です。

## そのほか

- **権利:** 素材の著作権は権利者にあります。このライセンスは、上の条件で使うことを認めるもので、権利を譲るものではありません。
- **免責:** 素材を使って生じたことについて、権利者は責任を負いません。
- **変更:** このライセンスは変えることがあります。変える前に入手・同梱したものには、変える前の条件が続きます。
- **ポスターの新しい版:** KawaPlayer の画面が変わったときは、新しい版を `Media~/poster/` に置きます。
- **準拠法:** このライセンスは日本法に従って解釈します。
