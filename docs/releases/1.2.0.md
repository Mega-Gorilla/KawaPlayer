**KawaPlayer 1.2.0** — 2026-09-03

今回の目玉はひとつ。**VHub プレイリストが、キューではなく「プレイリスト」として読み込まれるようになりました。**

これまでは、プレイリストを 1 つ読み込むとその曲がぜんぶキューに流し込まれていました。それだけでキューが埋まってしまい、別のプレイリストを聴きたくなったら一度消すしかない。複数のプレイリストを行ったり来たりするには、正直つらい作りでした。

1.2.0 では、読み込んだプレイリストはプレイリスト一覧に 1 件として並びます。5 件まで置いておけて、聴きたいものをタップするだけで切り替えられます。キューは空いたままなので、いつもどおり「次はこれ」を差し込むのに使えます。4 か月ぶりの更新、変わったところをざっくり紹介します！

## プレイリストは、プレイリストに入ります

* **読み込んだプレイリストはプレイリスト一覧に入ります。キューには触りません。** 最後まで再生しても消えず、先頭に戻ってループ。途中の曲をタップして選び直すこともできます。
* **複数のプレイリストを並べて、行ったり来たりできます。** 一度に持てるのは 5 件まで。6 件目を読み込もうとすると「これが消えますよ」と聞いてくれます。足りない？ ワールド制作者なら Unity 上で増やせます。
* **URL 欄に VHub の共有 URL を入れるだけ。** 専用の入力欄は無くなりました。動画 URL と同じ場所に貼れば、プレイヤーが勝手に見分けます。
* **名前の横に「更新」と「削除」ボタンが付きました。** VHub 側で曲を入れ替えたら、更新を押すだけ。同じ URL をもう一度入れても、増えずに更新されます。
* **結果を教えてくれるようになりました。** 何曲追加されたか、何曲飛ばしたか、失敗したならなぜか。以前は成功しても失敗しても無言でした。
* プレイリストの読み込みは、再生権限（PermissionManagement）を持つ人だけができます。

## Unity 側でも VHub プレイリストを使えます

* **Playlist Editor に共有 URL を貼ると、そのままワールドに焼き込めます。** VRChat 内で読み込むのと違ってサーバーに問い合わせないので、ワールドの初期プレイリストにぴったり。ただし焼き込んだ時点の内容で固定されるので、VHub 側で曲を入れ替えても自動では変わりません。反映したいときは Unity で同じ URL をもう一度取り込んで、ワールドを再アップロードしてください。常に最新にしておきたいなら、デフォルト動画 URL に VHub の URL を設定する方法がおすすめです。
* YouTube のプレイリスト取得に失敗しても、それまで入っていた曲は消えません。

## 細かいところ

* 確認ダイアログが、別の操作に横取りされなくなりました。「答えを待っているのに質問が消えた…」がもう起きません。
* 停止中の画面上部に、プレイヤー名・バージョンと「この欄に何を入れられるか」が出ます。
* YouTube の再生に失敗したとき、状況に合わせた案内を出します。VHub プレイリスト経由でも同じです。
* デフォルト動画 URL の設定欄は、権限が無い人にはその理由を表示します。以前は理由も無くただ消えていました。
* Playlist Panel のタブが表示されない問題、長いプレイリスト名が数文字しか見えない問題、日本語・中国語の文章が変な位置で折り返す問題を直しました。
* 本家 YamaPlayer の 2026-08-03 時点の更新を取り込んでいます。エラー後に停止できない、一時停止中に勝手に再生が始まる、といった不具合が直っています。

## 困ったら

まだ荒削りなところもあります。複数人で同時に触ったときの同期や、あとから入ってきた人への反映は、今回は試せていません。YouTube が再生できないときは、たいてい VRChat と YouTube のあいだの事情で、こちらでは直せないことが多いです。ごめんね。

「こんなことが起きた！」があれば、気軽に [Discord サーバー](https://discord.gg/tkrHek6PvN) で教えてください。あなたの報告が次のリリースを作ります。

## 入手方法

* **VCC:** リポジトリ `https://mega-gorilla.github.io/vpm-repos/index.json` を登録済みなら、もう更新候補に出ています。
* **VCC なし:** このページの `.unitypackage` をインポート。
* 1.1.x からの更新は、シーンの `KawaPlayer.prefab` をそのまま使えます。YamaPlayer からの移行は [README](https://github.com/Mega-Gorilla/KawaPlayer#yamaplayer-からの移行) を見てください。

*English:* The big one: a VHub playlist now loads as a **playlist**, not into the queue. Loading one used to fill the queue with every track, which made switching between playlists a chore. Now each one sits in the playlist list (up to five), you tap the one you want, and the queue stays free for "play this next" — paste the share URL into the normal URL field to load one. The Playlist Editor can bake a VHub playlist into the world too. Multi-user sync was not verified in this release; please tell us about anything odd on our [Discord server](https://discord.gg/tkrHek6PvN).
