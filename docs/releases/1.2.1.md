**KawaPlayer 1.2.1** — 2026-10-05

1.2.0 のプレイリスト機能を使ってもらう中で見つかった、「あれ？」となるところを直した小さな更新です。新しい機能は増えていませんが、いつもの操作が素直に動くようになりました。

いちばん分かりやすいのは**プレイリスト一覧の並び**です。途中のプレイリストを消してから新しいものを読み込むと、消した場所に入って「別のプレイリストに化けた」ように見えていました。1.2.1 からは、新しく読み込んだプレイリストは必ず一番下に並びます。

## 直したところ

* **プレイリスト一覧が、追加した順に並ぶようになりました。** 「更新」を押しても行は動きません。ワールドに入っているプレイリストは、これまでどおり先頭です。
* **キーボードを閉じただけで、前の URL がもう一度送られることがなくなりました。** URL 欄に前の URL が残っていると、入力画面をキャンセルで閉じただけで再生の確認が出たり、プレイリストの読み込みが始まったりしていました。
* **「再生 / キューに追加」の確認をキャンセルすると、URL 欄が空に戻ります。** 次に入力画面を開いたとき、さっきの URL が出てくることはありません。
* **デフォルト URL の設定でも、プレイリストを消す前に確認するようになりました。** プレイリストが一杯のときに VHub プレイリストをデフォルト URL に保存すると、いちばん古いプレイリストが黙って消えていました。URL 欄から読み込むときと同じく「これが消えますよ」と聞いてくれて、キャンセルすれば保存されません。
* README のデフォルト URL の説明を、実際の動きに合わせました。自動で流れるのは、オーナーが保存したときと、オーナーが自分で作ったインスタンスに入ったときです。あとから入ってきた人は、そのとき流れているものに合わせて再生されます。

## 困ったら

「こんなことが起きた！」があれば、気軽に [Discord サーバー](https://discord.gg/tkrHek6PvN) で教えてください。あなたの報告が次のリリースを作ります。

## 入手方法

VCC（VRChat Creator Companion）から入れます。KawaPlayer のリポジトリを追加済みなら、1.2.1 はもう更新候補に出ています。まだの人は、下の URL をブラウザのアドレスバーに貼って Enter を押すと VCC が開き、リポジトリが追加されます。あとは **Manage Project** からプロジェクトに **Add** するだけ。

```
vcc://vpm/addRepo?url=https://mega-gorilla.github.io/vpm-repos/index.json
```

VCC が開かない場合は、**Settings > Packages > Add Repository** に `https://mega-gorilla.github.io/vpm-repos/index.json` を入力してください。更新したら、ワールドをビルドし直してアップロードすると反映されます。

*English:* A small fix release for the playlist features from 1.2.0. The playlist list now keeps the order playlists were added in, so a new one always goes to the bottom instead of into the gap a deleted one left, and refreshing a row does not move it. Closing the keyboard no longer sends the URL left in the field again, and cancelling the play-or-queue question clears the field. Saving a VHub playlist as the default URL now asks before it pushes the oldest playlist out, just as the URL field does. Anything odd? Tell us on our [Discord server](https://discord.gg/tkrHek6PvN).
