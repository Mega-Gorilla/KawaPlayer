**KawaPlayer 1.3.1** — 2026-10-19

1.3.0 にしたら、Unity の Play でタブレットが動かない。そんなときがある問題を直した、小さな更新です。

## 更新する前に、これだけは読んでね

* **直したのは Unity のエディターだけです。** ワールドの中の動き（Udon）は 1.3.0 と同じなので、この修正のためにワールドをビルドし直す必要はありません。PC と Quest で 1.3.0 と 1.3.1 が混ざっても、そのまま一緒に遊べます。
* ワールドの中の更新履歴を新しくしたいときだけ、ビルドし直してアップロードしてください（下の「変わったこと」）。

## 直したこと

* **1.3.0 に更新したあと、Unity の Play でタブレットや全員リロードボタンが動かないことがある問題を直しました。** （#269）
  * **どんなとき：** Library フォルダーを消したあとや、プロジェクトを別の場所に写したあとに開いたときです。
  * **何が起きていたか：** U#（UdonSharp）がプログラムを作り直さないまま、「作り直した」と思い込んでいました。Console には `Could not load the program` と出て、本体も前の版のコードで動いていました。Unity を開き直しても直らない、なかなか頑固なやつでした。
  * **1.3.1 では：** Unity を開いたときに KawaPlayer の U# のプログラムを調べ、作り直されていなければ自動で作り直します。Console には `[KawaPlayer]` で始まる行が出ます。
  * **すでになっている人：** すでにこの状態になっていたプロジェクトも、1.3.1 に更新して開けば直ります。
  * **遊ぶ人：** 公開したワールドの遊ぶ人には影響しません。ワールドをビルドするとき、VRChat SDK が U# を作り直すからです（初めの設定のとき）。
* **それでも直らないときの手順を、ガイドに書きました。** Inspector の **Compile All UdonSharp Programs** を押す手順を、スクリーンショット付きで載せています。場所は、[インストールと更新](https://github.com/Mega-Gorilla/KawaPlayer/blob/develop/docs/guide/install.md)の「更新する」です。（#269）

## 変わったこと

* **ワールドの中の更新履歴に、直近 3 回の更新が出るようになりました。** Info パネルとタブレットのバージョン情報で見られます。これまでは、その版の分だけでした。

## 入手方法

VCC（VRChat Creator Companion）から入れます。KawaPlayer のリポジトリを追加済みなら、1.3.1 はもう更新候補に出ています。まだの人は、下の URL をブラウザのアドレスバーに貼って Enter を押してください。VCC が開き、リポジトリが追加されます。あとは **Manage Project** からプロジェクトに **Add** するだけです。

```
vcc://vpm/addRepo?url=https://mega-gorilla.github.io/vpm-repos/index.json
```

VCC が開かない場合は、**Settings > Packages > Add Repository** に `https://mega-gorilla.github.io/vpm-repos/index.json` を入力してください。

*English:*

A small fix for 1.3.0.

**What's fixed:**

* After updating to 1.3.0, the tablet and the Global Reload Button sometimes did not work in Unity's Play mode.
  * **When:** This happened when the project was opened without its Library folder, for example after deleting the Library or copying the project.
  * **Why:** U# (UdonSharp) did not rebuild its programs, but believed it had. The Console said `Could not load the program`, and the player ran the old version's code.
  * **Now:** KawaPlayer checks its U# programs when Unity opens and compiles them again if needed. A project already in this state is fixed when you update and open it.
  * **The manual fix:** Press **Compile All UdonSharp Programs** on any U# program asset. It is in the guide, with pictures (Japanese).
* Published worlds were not affected: the VRChat SDK compiles U# when it builds a world (with the default settings).
* Only the editor changed. You do not need to rebuild your world for this fix.

**What's changed:**

* The update log inside the world (the Info panel and the tablet's version info) now shows the last three updates.

Anything odd? Tell us on our [Discord server](https://discord.gg/tkrHek6PvN).
