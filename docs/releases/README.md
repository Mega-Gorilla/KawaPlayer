## 1.1.2 まで

1.1.2 と 1.0.0 の GitHub のリリースには本文がなく、1.1.0 と 1.1.1 にはリリースそのものがありません。ワールドの中の更新履歴（`Assets/updatelog.txt`）に書いていた内容を、そのままここに残します。

### 1.1.2（2026-05-06）

- デフォルト URL 機能を 9 言語対応（日本語・英語・韓国語・中国語簡体・中国語繁体・スペイン語・イタリア語・ロシア語・ウクライナ語）
- 入力欄に、今のデフォルト URL を自動で表示
- UI のデザインを改善

### 1.1.1

- 内部の改善のみ（使い方は変わりません）

### 1.1.0

- デフォルト URL 機能を追加
  - オーナーが、ワールドに入ったときに自動で再生される URL を、VRChat の中から設定できる
  - 設定した URL は、次に入ったときにも自動で戻る
  - 動画の URL と VHub のプレイリストの URL の両方に対応

### 1.0.0（2026-04-13）

- KawaPlayer の正式リリース（YamaPlayer ベース）
- VHub のプレイリストを読み込む機能を搭載
- シャッフル再生の不具合を修正
