**KawaPlayer 1.3.0** — YYYY-MM-DD

今回の目玉は、**持ち運べる KawaPlayer タブレット**です。

これまで、ワールドに置いた KawaPlayer を操作するには、スクリーンの前まで歩いていく必要がありました。1.3.0 では、手に持てるタブレットから、どこにいても操作できます。プレイリストも URL の入力も、手元でどうぞ。画像をみんなに見せたり、誰が来ているかを確かめたり、自分だけの見え方を変えたりもできます。

あわせて、見た目を KawaPlayer らしい「川の青」にしました。動画が再生できないときの手助けも増えています。変わったところを紹介します！

## タブレットを持ち歩けます

* **`GameObject > KawaPlayer > Tablet` から置いて、インスペクターで使う KawaPlayer を選ぶだけ。** 何台置いても大丈夫です。
* **KawaPlayer アプリ:** ワールドの KawaPlayer の画面がそのまま入っていて、再生・一時停止・シーク・音量・URL 入力・プレイリストを手元で操作できます。
* **画像アプリ:** URL を入れると画像を表示し、タブレットを見ている全員に同じ画像が映ります。タブレットを縦にすると、画像も回ります。
* **画像が出ないときは、その理由と、次にすることが出ます。** VRChat の設定で許可が必要なサイトなのか、サイトが VRChat からの読み込みを断っているのかなどを見分けて案内します。許可をオンにしたあとなどは、「もう一度読み込む」で読み直せます。
* **訪問者アプリ:** 今いる人と前にいた人の一覧、入退室のログ、アバターの顔写真を見られます。顔写真は、ワールド制作者がオフにできます。
* **設定アプリ:** 明るさ・左右反転・最大解像度・遅延補正・AudioLink・言語など、自分だけに効く設定を変えられます。インスタンスオーナーなら、自動再生の URL もここで決められます。
* **バージョン情報:** KawaPlayer の版と更新履歴が見られます。
* **開いているアプリは、見ている全員に同期します。** あとから入ってきた人にも、同じ画面が映ります。
* **画面の下のホームボタンは、白い □ が目印です。** アプリを開いているあいだは周りが LED のように青く光り、押すとホーム画面に戻ります。
* **VR では、触れたところのまま持てます。** 置き忘れたタブレットは、戻すボタンや、しばらく放っておくことで元の場所に戻せます（ワールド制作者の設定で使えます）。

## KawaPlayer の色になりました

* **UI の色を、YamaPlayer のピンクから KawaPlayer 独自の「川の青」に変えました。** タブレットも同じ色です。
* **何も再生していないときは、スクリーンに KawaPlayer のロゴが出ます。** これまでは真っ黒でした。ワールド制作者は、インスペクターの「待ち受け画像」で差し替えられます。
* **ワールド制作者は、色を 1 か所で変えられます。** 配色アセット（`KawaPlayerPalette`）を編集すれば、すべての UI に反映されます。YamaPlayer の配色も選べます。

## 再生できないときの手助け

* **エラーの下に「詳細」ボタンが出ます。** 押すと、直近のエラーの内容と、問い合わせ先の案内が出ます。その画面のスクリーンショットを送ってもらえれば、原因を探しやすくなります。
* **問い合わせ先の Discord の URL は、コピーできる欄に入っています。** VRChat ではワールドからリンクを開けないので、欄から写してブラウザに貼ってください。
* **ワールドの中で選べる動画プレイヤーを、AVPro にまとめました。** Unity Video Player は、AVPro で再生できないときの切り替え先として、これまでどおり使われます。

## 「デフォルト URL」は「自動再生」になりました

* **インスタンスオーナーが入室時に流す動画を決める機能の名前を、「デフォルト URL」から「自動再生」に変えました。** 中身はそのままで、保存した URL もそのまま使われます。
* **ワールド制作者向け:** モジュール管理では「自動再生(Owner)」と表示されます。YamaPlayer から引き継いだ AutoPlay は「自動再生(World)」です。(Owner) はインスタンスオーナーが VRChat の中で、(World) はワールド制作者が Unity で、流すものを決めます。
* **2 つの自動再生を両方とも有効にすると、モジュール管理とビルドのログにエラーが出ます。** どちらが流れるかが入室のタイミングで決まってしまうので、どちらか一方を使ってください。ビルドは止まりません。

## ワールド制作者向けの細かいところ

* **モジュール管理と KawaPlayer のインスペクターの一覧に、外部プレイリスト読込（PlaylistLoader）と自動再生(Owner) が出るようになりました。** 名前のない行や、出てこないモジュールはもうありません。
* **一覧の「無効化」は、モジュールの部品ごと切り替えます。** ビルドでも、部品ごと除かれます。
* **KawaPlayer に最初から入っているモジュールは、一覧から削除できなくなりました。** 消すと追加し直せないためです。使わないときは無効化してください。
* **同じモジュールを 2 つ置いたときのエラーが、KawaPlayer のインスペクターにも出ます。**

## 困ったら

「こんなことが起きた！」があれば、気軽に [Discord サーバー](https://discord.gg/tkrHek6PvN) で教えてください。動画が再生できないときは、画面の「詳細」ボタンの内容も添えてもらえると助かります。あなたの報告が次のリリースを作ります。

## 入手方法

VCC（VRChat Creator Companion）から入れます。KawaPlayer のリポジトリを追加済みなら、1.3.0 はもう更新候補に出ています。まだの人は、下の URL をブラウザのアドレスバーに貼って Enter を押すと VCC が開き、リポジトリが追加されます。あとは **Manage Project** からプロジェクトに **Add** するだけ。

```
vcc://vpm/addRepo?url=https://mega-gorilla.github.io/vpm-repos/index.json
```

VCC が開かない場合は、**Settings > Packages > Add Repository** に `https://mega-gorilla.github.io/vpm-repos/index.json` を入力してください。更新したら、ワールドをビルドし直してアップロードすると反映されます。タブレットは `GameObject > KawaPlayer > Tablet` から追加できます。
