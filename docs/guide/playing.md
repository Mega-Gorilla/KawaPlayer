# ワールドの中で使う

KawaPlayer が置かれたワールドで、スクリーンを操作する方法です。

## スクリーンを押す

スクリーンを押すと、操作が出ます。デスクトップでは視線（画面の中央）を向けて左クリック、VR ではコントローラーのレーザーを向けてトリガーを押してください。もう一度押すと隠れます。

操作は、右に [プレイリスト・キュー・履歴の一覧](#プレイリストキュー履歴の一覧) を開いた状態で出ます。下の画像は、その一覧を閉じたところです。左上に今の曲（①）、下にシークバー（②）と、3 つに分かれたボタン（③ 左・④ 真ん中・⑤ 右）が出ます。

![一覧を閉じたスクリーン。① 左上の今の曲、② シークバー、③ 左のボタン、④ 真ん中のボタン、⑤ 右のボタン に印がある](images/screen/controls.webp)

- **左上（①）:** 流れている曲の名前です。その下に、プレイリストの曲ならプレイリストの名前と何曲目か（「お気に入り · 1 / 8」）が、URL を入れて流した動画なら URL が出ます。止まっているときは、KawaPlayer のロゴと、入れられる URL の案内が出ます。
- **押せないボタン:** 押しても何も起きないボタンは、薄く出ます。たとえば、止まっているときの再生と停止や、プレイリストから流していないときの前の曲です。
- **ボタンの名前:** 左のボタンと設定は、指すと名前が出ます。

下の表の「反映」は、押したことがインスタンスの全員に反映されるか、自分にだけ反映されるかです。ワールドに権限管理のモジュールが入っているときは、権限のない人が押しても動かないボタンがあります（[権限管理](modules.md#権限管理)）。

### 左のボタン

![下の帯。左のボタンの ① URL を入力、② ループ再生、③ シャッフル再生、④ ReSync に印がある](images/screen/controls-left.webp)

| | ボタン | すること | 反映 |
| --- | --- | --- | --- |
| ① | **URL を入力**（鎖） | 動画やプレイリストの URL を入れる（[動画の URL を入れる](#動画の-url-を入れる)） | 全員 |
| ② | **ループ再生** | 今の動画を、終わったら最初から繰り返す。もう一度押すとやめる | 全員 |
| ③ | **シャッフル再生** | プレイリストの次の曲を、順番ではなくランダムに選ぶ。もう一度押すとやめる | 全員 |
| ④ | **ReSync** | 今の動画を、自分の画面で読み込み直す。読み込めたら、ほかの人と同じ位置から再生する。映像や音が止まったとき、自分の画面だけエラーで止まったとき、ずれが直らないとき、ライブ配信でほかの人より遅れているときに使う | 自分だけ |

一覧が開いているあいだは、**URL を入力**（①）だけが出ます。②〜④ は、一覧を閉じると出ます。

**ReSync** は、全員が止まっているときと、読み込み中のしばらくのあいだは押せません。読み込み中で押せないときは、少し待ってください。自分の画面だけエラーで止まったときは、すぐに押せます。

全員の画面をまとめて読み込み直すには、主催者などがワールドに置いた [全員リロードボタン](global-reload.md) を使います（置いてあるワールドだけ）。**ReSync** との違いは、[そのページ](global-reload.md#resync-との違い) にあります。

**ほかの人とずれたとき:** ふつうの動画は、ずれても自動で合わせ直すので、まず数秒待ってください。直らないときや、映像が止まったままのときは、**ReSync**（④）を押します。ライブ配信は自動では合わせないので、遅れたときは **ReSync** で今の位置から取り直します。いつも自分だけ早い・遅いときは、設定の **音声** の **ローカル再生遅延** で、自分の再生位置を前後にずらせます。くわしいしくみは [再生の同期のしくみ](technical/sync.md) にあります。

### 真ん中のボタンとシークバー

![下の帯。① シークバー、② 前の曲、③ 再生・一時停止、④ 次の曲、⑤ 停止 に印がある](images/screen/controls-middle.webp)

| | ボタン | すること | 反映 |
| --- | --- | --- | --- |
| ① | **シークバー** | つまみを動かすと、その位置から再生する。左は今の位置、右は動画の長さ | 全員 |
| ② | **前の曲** | 再生中のプレイリストの、1 つ前の曲を流す（最初の曲なら最後の曲へ） | 全員 |
| ③ | **再生**・**一時停止** | 再生と一時停止を切り替える | 全員 |
| ④ | **次の曲** | キューに曲があればその曲を、なければ再生中のプレイリストの次の曲を流す（最後の曲なら最初の曲へ。シャッフル再生ならランダム）。キューの曲を流したあとは、プレイリストの続きには戻らない | 全員 |
| ⑤ | **停止** | 再生をやめる。エラーで止まったときの表示も消える | 全員 |

**前の曲** と **次の曲** は、プレイリストから流しているときに使えます。URL を入れて流した動画や、キューから流した曲のあとは、キューに曲があるときだけ **次の曲** が働きます。

![右のボタンの上に開いた音量の板。① 今の音量、② バー、③ 消音のボタン に印がある](images/screen/volume.webp)

## プレイリスト・キュー・履歴の一覧

スクリーンを押して操作を出すと、スクリーンの右に一覧が出ています。上のタブ（①〜③）で、出すものを切り替えます。最初は **プレイリスト** のタブです。

![一覧を開いたスクリーン。① プレイリスト、② キュー、③ 履歴 のタブ、④ プレイリスト「お気に入り」、⑤ 指すと左に寄って「VHub Playlist URLで追加」と出る ＋ の行、⑥ 右下の ∨ に印がある](images/screen/playlist-list.webp)

| | タブ | 出るもの |
| --- | --- | --- |
| ① | **プレイリスト** | ワールドに最初から入っているプレイリストと、VHub から読み込んだプレイリストの一覧。プレイリスト（④）を押すと、その曲の一覧が出る（[下の手順](#プレイリストから曲を流す)） |
| ② | **キュー** | 次に流す曲の列。URL を入れたときの **再生キューに追加する** や、曲の **キューに追加** で足した曲が並ぶ。次の曲に進むときは、プレイリストより先に、キューの曲を上から流す |
| ③ | **履歴** | これまでに流した曲 |

- **＋（⑤）:** VHub のプレイリストを、一覧に足します。＋ の行を指すと、＋ が左に寄り、その右に **VHub Playlist URLで追加** と出ます。行のどこを押しても、VHub の VRChat用URL を入れる欄が開きます。貼って確定すると、プレイリストの一覧の最後に 1 つ足されます。止まっていても再生は始まらず、足せたことも表示しません（読み込めなかったときだけ、理由が出ます）。動画の URL は入れられないので、下の帯の **URL を入力** から入れてください。Playlist Panel には出ません（[VHub のプレイリストを読み込む](#vhub-のプレイリストを読み込む)）。
- **閉じる:** もう一度 **一覧** を押すか、右下の **∨**（⑥）を押すか、一覧の外を押します。次に操作を出すと、また開いています。
- **下の帯:** 一覧が出ているあいだ、帯は一覧の左に縮みます。左のボタンは **URL を入力** だけが残り、**ループ再生**・**シャッフル再生**・**ReSync** と、**設定**・**その他** は隠れます。

### キュー

**キュー**（①）を押すと、次に流す曲（②）が並びます。

![キューのタブ。① キューのタブと、② 並んだ 3 曲に印がある](images/screen/queue.webp)

- **足し方:** URL を入れたときの確認で **再生キューに追加する** を押すか、履歴やプレイリストの曲の **キューに追加** を押します。
- **流れ方:** 曲が終わったときや **次の曲** を押したとき、キューの一番上の曲が流れ、キューから消えます。シャッフル再生のときは、キューの中からランダムに選びます。
- **プレイリストとの関係:** キューの曲を流すと、プレイリストの続けての再生から離れます。キューを流し終えても、元のプレイリストの続きは流れません。続けたいときは、プレイリストの曲を選んで **再生する** を押してください。キューが空で、プレイリストから流しているときは、プレイリストの次の曲に進みます。

キューの曲を押すと、その行が **戻る**（①）・**上へ移動**（②）・**下へ移動**（③）・**削除**（④）に変わります。上へ移動・下へ移動で流す順番を入れ替え、削除でキューから外します。

![キューの 2 曲目の行が操作ボタンに変わったところ。① 戻る、② 上へ移動、③ 下へ移動、④ 削除 に印がある](images/screen/queue-actions.webp)

### 履歴

**履歴**（①）を押すと、これまでに流した曲（②）が、流した順に上から並びます（一番下が、最後に流した曲）。曲を押すと、プレイリストの曲と同じ操作ボタン（戻る・URL・キューに追加・再生する）が出ます。もう一度流したい曲を探すときに使います。

![履歴のタブ。① 履歴のタブと、② 流した 1 曲に印がある](images/screen/history.webp)

### プレイリストから曲を流す

1. **プレイリスト** のタブで、流したいプレイリストを押します（[上の画像](#プレイリストキュー履歴の一覧) の ④）。
2. そのプレイリストの曲の一覧に変わります。上には、**<**（①）と、プレイリストの名前と曲数（②）が出ます。流したい曲（③）を押します。**<** を押すと、プレイリストの一覧に戻ります。流れている曲は、番号の代わりに音符が付き、名前が色付きで出ます（④）。

   ![プレイリスト「お気に入り」の曲の一覧。① 左上の <、② 名前と曲数、③ 2 曲目、④ 流れている 3 曲目 に印がある](images/screen/playlist-tracks.webp)

3. 押した曲の行が、その曲の操作ボタンに変わります。**再生する**（④）を押すと、その曲から再生します。

   ![2 曲目の行が操作ボタンに変わったところ。① 戻る、② URL、③ キューに追加、④ 再生する に印がある](images/screen/track-actions.webp)

#### 曲の操作ボタン

曲を押したときに出るボタンを、まとめておきます。タブによって、出るボタンが違います。

| ボタン | すること | 出るタブ |
| --- | --- | --- |
| **戻る**（←） | 操作ボタンを閉じて、曲の行に戻す | すべて |
| **URL**（2 枚の紙） | 曲名と URL の画面を出す。URL は欄からコピーできる（Playlist Panel には出ない） | 履歴・プレイリスト |
| **キューに追加**（＋） | その曲を、キューの最後に足す | 履歴・プレイリスト |
| **再生する**（▶） | その曲から再生する | 履歴・プレイリスト |
| **上へ移動**（△）・**下へ移動**（▽） | キューの中で、順番を入れ替える | キュー |
| **削除**（✕） | キューから外す | キュー |

#### VHub から読み込んだプレイリスト

VHub から読み込んだプレイリストの曲の一覧には、名前の右に **…**（①）が出ます。押すと、その下に **更新**（②）・**URL**（③）・**削除**（④）が並びます。

![VHub から読み込んだプレイリスト『作業用BGM』の曲の一覧で、… を押したところ。① …、② 更新、③ URL、④ 削除 に印がある](images/screen/playlist-vhub.webp)

| | ボタン | すること |
| --- | --- | --- |
| ① | **…** | ②〜④ のボタンを出す。もう一度押すと隠す |
| ② | **更新** | VHub の今の内容に変える |
| ③ | **URL** | 読み込んだ VRChat用URL の画面を出す。URL は欄からコピーできる |
| ④ | **削除** | プレイリストの一覧から外す（外す前に確認が出る） |

ワールドに最初から入っているプレイリストには、**…** は出ません。Playlist Panel にも出ないので、更新や削除はスクリーンかタブレットでします。

## 動画の URL を入れる

1. 左のボタンの **URL を入力**（②、鎖のボタン）を押すと、VRChat の入力欄が開きます。止まっているときは、このボタンが色の付いた丸で出ます。左上には、入れられる URL の案内（①）が出ます。

   ![止まっているスクリーン。① 左上の、入れられる URL の案内と、② URL を入力（鎖のボタン）に印がある](images/screen/url-button.webp)

2. 動画の URL（YouTube など）を貼って、確定します。

止まっているときは、すぐに再生が始まります。ほかの動画を再生しているときは、**URLを再生する** の確認が出ます。

![URL を再生する の確認。① プレイヤーの選択、② キャンセル、③ 再生キューに追加する、④ 再生する に印がある](images/screen/url-confirm.webp)

| | 部分 | すること |
| --- | --- | --- |
| ① | **AVPro Video Player**・**画像表示** | この URL を流すプレイヤー。動画はそのまま AVPro で、画像の URL なら **画像表示** を選ぶ。選んだプレイヤーは、この URL にだけ使う |
| ② | **キャンセル** | やめる |
| ③ | **再生キューに追加する** | 再生キューの最後に足して、順番に流す |
| ④ | **再生する** | 今の動画を止めて、入れた URL を再生する |

### VHub のプレイリストを読み込む

[VHub Playlist](https://playlist.vrc-hub.com) のプレイリストも、同じ **URL を入力** で、まるごと読み込めます。一覧の **＋** からも足せます（下の 2.）。

**先に、VRChat の設定で Allow Untrusted URLs をオンにしてください**（[オンにする手順](quickstart.md#7-allow-untrusted-urls-をオンにする)）。オフのままでは読み込めず、VHub の曲も流れません。Public・Group Public のインスタンスでは、ワールドが VHub を許可している必要もあります（ワールドの作者が設定します）。

1. VHub で、プレイリストの **VRChat用URL** をコピーします（[コピーのしかた](vhub.md#vrchat用url-をコピーする)）。
2. **URL を入力**（①）に貼って、確定します。**プレイリストを追加しました** と出れば、プレイリストの一覧に 1 つ足されています。止まっているときは、そのまま再生が始まります。

   ![「プレイリストを追加しました」の表示。『作業用BGM』の 12 曲を読み込んだ。① URL を入力 に印がある](images/screen/playlist-loaded.webp)

   一覧の **プレイリスト** のタブの下にある **＋** に貼っても、同じように足せます。こちらは止まっていても再生が始まらず、**プレイリストを追加しました** も出ません。読み込めたプレイリストが、一覧の最後に出ます（[一覧](#プレイリストキュー履歴の一覧) の ⑤）。

3. 一覧の **プレイリスト** のタブで、読み込んだプレイリストを選びます。曲（①）を押して、出てきた **再生する** を押すと、その曲から再生します。名前の右の **…**（②）から、**更新** で VHub の今の内容に変え、**削除** で一覧から外せます（[VHub から読み込んだプレイリスト](#vhub-から読み込んだプレイリスト)）。

   ![プレイリスト『作業用BGM』の曲の一覧。① 1 曲目と、② 名前の右の … に印がある](images/screen/playlist.webp)

- **入れる URL:** VHub のページのアドレス（`/playlists/…`）や、**シェア** でコピーした URL では読み込めません。**VRChat用URLをコピー** でコピーした URL（`https://playlist.vrc-hub.com/r/default/…`）を入れます。
- **読み込める数:** 標準で 5 件までです。いっぱいのときに新しく読み込むと、一番古いものを消してよいか聞かれます（[プレイリスト](playlists.md#ワールドの中で-vhub-のプレイリストを読み込む)）。

## 設定を変える

右のボタンの **設定**（歯車）を押すと、設定の画面が出ます。左の分類（②）の **再生**・**映像**・**音声**・**言語** を切り替え、左上の **←**（①）で元の画面に戻ります。

![設定の画面。再生の分類で、動画プレイヤー・再生速度・区間リピート再生が並ぶ。① 左上の ←、② 左の分類、③ 下の (Global) の説明 に印がある](images/screen/settings.webp)

名前に **(Global)** が付いた設定は、インスタンスの全員に反映されます。付いていない設定は、自分にだけ反映されます（下の ③ にも書いてあります）。

### 再生

![設定の再生の分類。① 動画プレイヤー、② 再生速度、③ 区間リピート再生 に印がある](images/screen/settings-playback.webp)

下へ送ると、④ が出ます。

![再生の分類を下へ送ったところ。④ 自動再生 に印がある](images/screen/settings-playback2.webp)

| | 設定 | すること | 反映 |
| --- | --- | --- | --- |
| ① | **動画プレイヤー** | 次に入れる URL を流すプレイヤー。**AVPro**（動画。YouTube Live や Twitch の配信も見られる）か、**画像表示**（画像）。動画を流すときは AVPro のままにする | 全員 |
| ② | **再生速度** | 0.05 倍きざみで、0.05〜2.0 倍。真ん中が 1.0 倍。AVPro では、変えると動画を読み込み直す | 全員 |
| ③ | **区間リピート再生** | バーの左右のつまみで区間（A〜B）を決めて **オン** にすると、その区間を繰り返す。決めた区間は、バーの下のスタート(A)・エンド(B) に出る。動画が変わると、自動でオフに戻る。ライブ配信では使えない | 全員 |
| ④ | **自動再生** | 入室時に流す動画・プレイリストの URL。決められるのはインスタンスを作った人だけ（[自動再生](#自動再生)） | 全員 |

### 自動再生

**再生** の分類の一番下（④）にある、インスタンスを作った人（インスタンスオーナー）が、入室したときに流す動画やプレイリストを決める機能です。タブレットの設定アプリの **再生** にも、同じ欄があります。

#### 見る人ごとの表示

自動再生の欄は、見る人によって表示が変わります。

| 見る人 | 表示 |
| --- | --- |
| インスタンスを作った人 | 決めた URL（設定値）と、**URLを入力**・**クリア** のボタン |
| ほかの人 | 「✕ 本機能は利用できません」と理由だけ。操作はできない |
| Public・Group のインスタンスと、SDK の Build & Test | インスタンスを作った人がいないので、全員が「✕ 本機能は利用できません」 |

**インスタンスを作った人の画面:**

![インスタンスを作った人の自動再生の欄。設定値は (未設定)。① URLを入力、② クリア に印がある](images/screen/autoplay-owner.webp)

**ほかの人の画面**（Public・Group のインスタンスでは全員）:

![ほかの人の自動再生の欄。「✕ 本機能は利用できません」と、インスタンスオーナーのみ利用でき、Public / Group インスタンスでは利用できないという理由が出ている](images/screen/autoplay-other.webp)

#### 自動再生の URL を設定する

1. **URLを入力**（上の画像の ①）を押し、動画の URL か、VHub のプレイリストの VRChat用URL（[コピーのしかた](vhub.md#vrchat用url-をコピーする)）を貼って、確定します。
2. 設定値（①）に、決めた URL が出ます。

   ![URL を決めたあとの自動再生の欄。① 設定値に URL が出ている](images/screen/autoplay-owner-set.webp)

- **全員に反映:** 名前の (Global) のとおり、決めた URL はインスタンスの全員に反映されます。
- **すぐ流れるとき:** 止まっているときに決めると、すぐに全員で再生が始まります。何かを再生しているときは止めず、そのインスタンスでは、あとから流れることもありません。
- **VHub のプレイリスト:** プレイリストの一覧に読み込みます。読み込める枠（標準で 5 件）がいっぱいのときは、一番古いものを消してよいか聞かれます。

#### 自動再生の URL を消す

**クリア**（上の画像の ②）を押すと、決めた URL が消え、設定値が **(未設定)** に戻ります。いま流れているものは止まりません。

#### 次のインスタンスでも流れる

決めた URL は、決めた人の VRChat のアカウントに残ります。同じワールドで次に自分でインスタンスを作って入ると、その URL が設定値に戻り、止まっていれば自動で流れます。流したくなくなったら、**クリア** で消してください。

ワールドの作者が Unity で決める自動再生（自動再生(World)）とは別の機能で、同じ KawaPlayer で両方は使えません（[モジュール](modules.md#自動再生owner)）。

## 再生できないとき

**自分の画面だけ止まったとき:** ほかの人には映っているのに、自分の画面だけエラーで止まったり、読み込み中のまま進まなかったりするときは、まず **ReSync**（[左のボタンの ④](#左のボタン)）を押してください。押した人の画面だけが読み込み直し、ほかの人と同じ位置に戻ります（一時停止中なら、一時停止のまま）。それでも再生できないときや、全員が再生できないときは、下の **詳細** と、原因ごとの案内を見てください。

再生できないと、スクリーンに理由と **詳細** ボタンが出ます。

![再生できなかったときの表示。「Invalid URL...」の案内と、印の付いた「詳細」ボタン](images/screen/error.webp)

**詳細** を押すと、直近のエラーの内容と、問い合わせ先の Discord の URL が出ます。この画面のスクリーンショットを添えて Discord で聞いてもらえると、原因を探しやすくなります。VRChat ではワールドからリンクを開けないので、Discord の URL は欄（①）からコピーして、ブラウザに貼ってください。**閉じる**（②）で元の画面に戻ります。

![再生エラーの詳細。エラーの一覧の下の、① Discord の URL をコピーできる欄と ② 閉じる に印がある](images/screen/error-details.webp)

### Access Denied と出たとき

VRChat が初めから信頼していないサイトの動画は、見る人それぞれが VRChat の設定で **Allow Untrusted URLs** をオンにしていないと流れません（[オンにする手順](quickstart.md#7-allow-untrusted-urls-をオンにする)）。

- **遊ぶ人:** まず Allow Untrusted URLs をオンにしてください。それでも再生できないときは、ワールドの制作者に伝えてください。Public・Group Public のインスタンスでは、ワールドが許可したサイトの動画しか流せず、その許可を変えられるのはワールドの制作者だけです。**詳細** の画面を撮って見せると、制作者は何をすればよいか分かります。
- **ワールドの制作者:** **詳細** の直近のエラーの下に、Video Player Allowed Domains に足すドメインが出ます（スクロールした先にあります）。[クイックスタートの 6.](quickstart.md#6-vrchatcom-で-vhub-を許可する) と同じ手順で、そのドメインを足してください。Public・Group Public 以外のインスタンスでは、この一覧は要りません。
- **画像のとき:** 画像を映しているときの Access Denied は、Allow Untrusted URLs だけで直ります。ワールドの許可は要らないので、**詳細** に制作者向けの案内は出ません。

![再生エラーの詳細をスクロールしたところ。直近のエラーの下の、ワールドの制作者向けの案内（Video Player Allowed Domains に playlist.vrc-hub.com を足す）に印がある](images/screen/error-access-denied.webp)
