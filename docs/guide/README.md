# KawaPlayer の使い方

KawaPlayer は、VRChat のワールドに置く動画プレイヤーです。YouTube などの動画のほか、[VHub Playlist](https://playlist.vrc-hub.com) のプレイリストを、ワールドの中で URL を貼るだけで読み込めます。

## 初めての人へ

**[クイックスタート](quickstart.md)** から始めてください。KawaPlayer を入れるところから、ワールドの中で動画を流すまでを、1 ページで説明しています。

1. [VCC に KawaPlayer のリポジトリを追加する](quickstart.md#1-vcc-に-kawaplayer-のリポジトリを追加する)
2. [プロジェクトに KawaPlayer を入れる](quickstart.md#2-プロジェクトに-kawaplayer-を入れる)
3. [シーンに KawaPlayer を置く](quickstart.md#3-シーンに-kawaplayer-を置く)
4. [タブレットを置く](quickstart.md#4-タブレットを置く)
5. [ビルドして確かめる](quickstart.md#5-ビルドして確かめる)
6. [VRChat.com で VHub を許可する](quickstart.md#6-vrchatcom-で-vhub-を許可する)
7. [Allow Untrusted URLs をオンにする](quickstart.md#7-allow-untrusted-urls-をオンにする)
8. [ワールドの中で動画を流す](quickstart.md#8-ワールドの中で動画を流す)
