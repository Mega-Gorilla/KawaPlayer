# KawaPlayer の使い方

KawaPlayer を、ワールドに置くところから、ワールドの中で使うところまで、画像付きで説明します。

初めての人は、**[クイックスタート](quickstart.md)** から始めてください。KawaPlayer を入れて、置いて、ビルドして、ワールドの中で動画を流すまでを、1 ページで説明しています。

## カテゴリーごとのページ

| ページ | 内容 | 読む人 |
| --- | --- | --- |
| [クイックスタート](quickstart.md) | 入れる、置く、タブレットを置く、ビルドする、VHub を許可する、Allow Untrusted URLs をオンにする、動画を流す | 制作者・遊ぶ人 |
| [インストールと更新](install.md) | リポジトリのほかの追加方法、更新、シーンへの置き方 | 制作者 |
| [KawaPlayer の設定](settings.md) | インスペクターの各欄（外観、動画プレイヤー、プレイリスト、バージョン） | 制作者 |
| [プレイリスト](playlists.md) | 最初から入れておくプレイリスト（VHub・YouTube・ほかのプレイヤーから）、ワールドの中での VHub の読み込み | 制作者・遊ぶ人 |
| [VHub Playlist の使い方](vhub.md) | VHub のプレイリストの URL のコピー、プレイリストの作り方と直し方 | 制作者・遊ぶ人 |
| [モジュール](modules.md) | 最初から入っている機能（自動再生(Owner)・外部プレイリスト読込）と、追加できる機能 | 制作者 |
| [タブレット](tablet.md) | 置き方と設定、アプリの使い方 | 制作者・遊ぶ人 |
| [ワールドの中で使う](playing.md) | スクリーンの操作、URL の入れ方、設定、再生できないとき | 遊ぶ人 |

困ったときは、気軽に [Discord サーバー](https://discord.gg/tkrHek6PvN) で聞いてください。

画像の作り方は、[images/README.md](images/README.md) にあります。
