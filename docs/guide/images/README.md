# 使い方ガイドの画像

[使い方ガイド](../README.md) の画像です。写っている場所ごとに、フォルダーを分けています。

| フォルダー | 写っているもの |
| --- | --- |
| `vcc/` | VCC と、VCC 用のページ（vpm-repos） |
| `unity/` | Unity のエディター（メニュー、インスペクター、プレイリストエディター、モジュール管理） |
| `screen/` | ワールドの中の、KawaPlayer のスクリーン |
| `tablet/` | ワールドの中の、タブレット |
| `original/` | 上の 4 つと同じ名前の、印を付ける前の画像 |

## 印の付け方

ガイドの画像には、押す場所や入れる場所に印（枠・番号・矢印つきの説明）があります。印は `annotate.py` が `original/` の画像に描いたもので、画像を直接は編集しません。

1. 撮り直したときは、印のない画像を、`original/` の同じ名前で置き換えます。
2. 印の位置や文言は、`annotate.py` の `MARKS` を直します。座標は `original/` の画像の画素です。
3. `python annotate.py <フォント> [名前 ...]` で作り直します。フォントは [Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic) の Regular で、Pillow が要ります。名前を省くと、全部を作り直します。

本文の ①② は、画像の番号と合わせてください。

## 大きさと形式

形式はどれも WebP です（`docs/` はパッケージの zip に入りますが、Unity は WebP をテクスチャーとして読み込みません）。1 枚 60 KB 以下が目安です。

| 画像 | 大きさ | 圧縮（`original/`） | 圧縮（印付き） |
| --- | --- | --- | --- |
| ワールドの中（`screen/`・`tablet/`） | 幅 1280 に縮める | 品質 90 | 品質 80 |
| VCC と Unity（`vcc/`・`unity/`） | 撮ったまま（縮めると文字がにじむ） | 可逆圧縮 | 可逆圧縮と品質 90 の小さいほう |

印の説明を画像の外に置くときは、`MARKS` の `pad` で余白を足します。余白は、その画像で一番多い色になります。

## 写すもの

- 曲名・プレイリスト名は見本の名前にします。テスト用のプロジェクトのものは、実在の曲です。
- ほかのツールのメニューなど、ガイドに要らないものが写ったときは、`original/` に置く前に切り取るか消します。
