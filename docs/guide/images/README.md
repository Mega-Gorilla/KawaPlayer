# 使い方ガイドの画像

[使い方ガイド](../README.md) の各ページの画像です。写っている場所ごとに、フォルダーを分けています。

| フォルダー | 写っているもの |
| --- | --- |
| `vcc/` | VCC と、VCC 用のページ（vpm-repos） |
| `unity/` | Unity のエディター（メニュー、インスペクター、プレイリストエディター、モジュール管理） |
| `vrchat/` | VRChat のメニュー（クイックメニューと設定）と、VRChat のサイト（My Worlds、Edit World Info） |
| `screen/` | ワールドの中の、KawaPlayer のスクリーン |
| `tablet/` | ワールドの中の、タブレット |
| `vhub/` | VHub Playlist のサイト |
| `original/` | 上の 6 つと同じ名前の、印を付ける前の画像（`src` で元を指定した画像は、その元を使う） |

## 印の付け方

ガイドの画像には、押す場所や入れる場所に印（枠・番号・矢印つきの説明）があります。印は `annotate.py` が `original/` の画像に描いたもので、画像を直接は編集しません。

1. 撮り直したときは、印のない画像を、`original/` の同じ名前で置き換えます。
2. 印の位置や文言は、`annotate.py` の `MARKS` を直します。座標は `original/` の画像の画素です。同じ画像に別の印を付けたものが要るときは、新しい名前で足し、`src` に元の画像の名前を書きます（タブレットを置くメニューの `unity/gameobject-menu-tablet` がそうです）。一部だけを切り出すときは、`crop` に残す範囲を書きます（設定のページの `unity/inspector-*` がそうです）。
3. `python annotate.py <フォント> [名前 ...]` で作り直します。フォントは [Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic) の Regular で、Pillow が要ります。名前を省くと、全部を作り直します。

本文の ①② は、画像の番号と合わせてください。

## 大きさと形式

形式はどれも WebP です（`docs/` はパッケージの zip に入りますが、Unity は WebP をテクスチャーとして読み込みません）。1 枚 60 KB 以下が目安です。

VCC と Unity の画面は、たいてい可逆圧縮のほうが小さく、文字もにじみません。撮った画像にノイズがあるときなどは、品質 90 のほうが小さくなります。どちらにするかは、スクリプトが画像ごとに選びます。

| 画像 | 大きさ | 圧縮（`original/`） | 圧縮（印付き） |
| --- | --- | --- | --- |
| ワールドの中、VRChat のメニュー、VHub のサイト（`screen/`・`tablet/`・`vrchat/`・`vhub/`） | 幅 1280 以下に縮める | 品質 90 | 品質 80 |
| VCC と Unity（`vcc/`・`unity/`） | 撮ったまま（縮めると文字がにじむ） | 可逆圧縮と品質 90 の小さいほう | 可逆圧縮と品質 90 の小さいほう |

印の説明を画像の外に置くときは、`MARKS` の `pad` で余白を足します。余白は、その画像で一番多い色になります。

## 写すもの

- 曲名・プレイリスト名は見本の名前にします。テスト用のプロジェクトのものは、実在の曲です。ただし、トラックリストの画像（`unity/playlist-tracks`）は、持ち主の許可を得て実在のプレイリストを写しています。
- ほかのツールのメニューやタブなど、ガイドに要らないものが写ったときは、`original/` に置く前に切り取るか消します。タブレットの向きの画像（`tablet/rotate`）は、横と縦に持って撮った 2 枚を、同じ縮尺で並べています。Hierarchy の画像（`unity/hierarchy-empty`）は、テスト用のシーンにあるほかの方の商品の行を除き、上（KawaPlayer の行まで）と一覧の下の空いたところをつなげています。
- VRChat のメニューとサイトは、名前・ステータス・アバターの画像・V の残高、広告のバナー、ほかの人のアバターやイベントやワールド、公開していない自分のワールドが写らないように切り取ります。`original/` も切り取ったものを置きます。
- VHub のサイトは、ログインしたアカウントのアイコンと名前、マイライブラリの一覧、ほかの人のプレイリストが写らないように切り取ります。切り取れない作者の名前は、ぼかします。プレイリストを作る画面は、見本のプレイリスト（『作業用BGM』、[Blender Foundation](https://studio.blender.org/films/) の CC BY の映画）で撮り、撮ったあとで消します。
- Unity のエディターは、ダークテーマのまま撮ります。スクリプトで窓を撮るときは、テスト用のプロジェクトがリニア色空間なので、色が sRGB に 2 回変換されて白っぽくなります。保存する前に sRGB からリニアへ戻し、背景が暗い灰色（60, 60, 60 くらい）になっているか確かめてください。
