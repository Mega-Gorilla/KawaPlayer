# モジュール

KawaPlayer の機能の一部は、モジュールとして分かれていて、足したり切ったりできます。インスペクターの **モジュール管理** を押すと、モジュールの一覧が出ます。

![モジュール管理。① インストール済みの 2 つのモジュールと、② 利用可能なモジュールの追加ボタンに印がある](images/unity/module-manager.webp)

## 最初から入っているモジュール

画像の ① です。KawaPlayer を置いたときから入っていて、有効になっています。何もしなくても使えます。

| モジュール | すること |
| --- | --- |
| **自動再生(Owner)** | インスタンスを作った人（Instance Owner）が、VRChat の中で、入室時に流す動画やプレイリストを決める |
| **外部プレイリスト読込** | VHub のプレイリストを、ワールドの中の URL の欄から読み込む（[プレイリスト](playlists.md#ワールドの中で-vhub-のプレイリストを読み込む)） |

- **設定:** そのモジュールの設定を開きます。
- **無効化:** 使わない機能を切ります。**有効化** で戻せます。
- **削除:** この 2 つは KawaPlayer のプレハブに入っていて、消すと足し直せないので、削除はできません。使わないときは無効化してください。

### 自動再生(Owner) のしくみ

- **決める人:** インスタンスを作った人にだけ、スクリーンとタブレットの設定の **再生** に、**自動再生** の欄が出ます。ここに動画かプレイリストの URL を入れると、入室したときに流れます。
- **全員に反映:** 決めた URL は、そのインスタンスの全員に反映されます。止まっているときに決めると、すぐに全員で再生が始まります。
- **次のインスタンスでも:** 決めた URL はその人のアカウントに残り、次に自分で作ったインスタンスでも使われます。
- **使えないところ:** Public・Group のインスタンスと、SDK の Build & Test では、インスタンスを作った人がいないので使えません。

## 追加できるモジュール

画像の ② です。**追加** を押すと、そのモジュールが KawaPlayer に入ります。

| モジュール | すること |
| --- | --- |
| **AudioLink アダプター** | AudioLink の動画連動を、自動で設定する |
| **自動再生(World)** | ワールド制作者が Unity で決めた動画・プレイリストを、入室時に自動再生する。どのインスタンスでも流れる |
| **Light Volume アダプター** | VRC Light Volumes の動画連動を、自動で設定する |
| **LTCGI アダプター** | LTCGI の動画連動を、自動で設定する |
| **権限管理** | 動画プレイヤーを操作できる人を決める |
| **設定の永続化** | ワールドに入り直したときに、設定を戻す |
| **ピッチシフター** | 再生速度を変えずに、音程を変える（カラオケ向け） |
| **スライドショー** | 動画をスライドとして、ページごとに切り替える |
| **Timeline 同期** | 動画の URL に合わせて、Timeline を同期して再生する |
| **動画情報取得** | YouTube や Twitch から、動画のタイトルを自動で取ってくる |

**自動再生(World)** を足すときは、**自動再生(Owner)** を無効化してください。どちらも入室時に再生を始めるので、両方が有効だと、どちらが流れるかが入室のタイミングで変わります。両方が有効なときは、モジュール管理・インスペクター・ビルドのログにエラーが出ます。
