## 要旨

KawaPlayer を紹介する、約 90 秒の動画の絵コンテである。特定の版ではなく、「KawaPlayer とは何か、何ができるか、どう入れるか」を伝える。夜の部屋で MAO がタブレットを手に取り、スクリーンが点くところから始まる。続いて、KawaPlayer らしい機能を 5 つの章で見せる：VHub のプレイリスト、みんなで同じ映像、タブレット、自動再生、全員リロードボタン。最後に、ほかの機能を短く重ね、VCC での導入と、Booth・入れ方のページへの案内で締める。ナレーションは入れず、テロップ・吹き出し・BGM で進める。カットは 23 で、尺は 90.5 秒である。

**キーワード：** 紹介動画、絵コンテ、HyperFrames、Unity Recorder

## 1. はじめに

### 1.1 目的

KawaPlayer が何をできるのかを、文章を読まなくても分かるようにする。Booth の商品ページや X で目に留まり、そのまま入れてみたくなる動画を目指す。

### 1.2 見せたい人と出す場所

- **見せたい人：** VRChat のワールド制作者。ワールドで遊ぶ人にも伝わる見せ方にする。
- **出す場所：** Booth の商品ページ、X、YouTube。
- **GitHub：** 動画のファイルは上げず、README からリンクする（[2.2](#22-登場人物)）。

### 1.3 形

| 項目 | 内容 |
| --- | --- |
| 長さ | 約 90 秒（この絵コンテでは 90.5 秒） |
| 画面 | 16:9、1920 × 1080、30 fps |
| 声 | ナレーションなし。テロップ・吹き出し・BGM・効果音で進める |
| 言葉 | 日本語。章の見出しとテロップに、英語の一行を添える（[5 章](#5-決めること)） |

### 1.4 参考にした構成

いくつかの紹介動画を見て、次の流れにした。

1. 映画のような始まり。
2. 題名。
3. 機能ごとの短い場面。左下の見出しに、番号と機能の名前を出す。
4. 締めの言葉と案内。

機能は、人物どうしのやり取りで見せる。手元の操作は持つ人の目線で、会話は外から撮る。吹き出しで、ちょっとした冗談を混ぜる。

## 2. 前提

### 2.1 撮り方

カットごとに、次のどれで作るかを〔 〕に書いた。

| 印 | 作り方 |
| --- | --- |
| 〔Unity〕 | テスト用のプロジェクトにアバターを置いて動かし、Unity Recorder で撮る。KawaPlayer は Play で実際に動かす |
| 〔画面の録画〕 | ブラウザ（VHub）、VCC、Unity のエディターを録る |
| 〔HyperFrames〕 | 題名、見出し、テロップ、画面の分割、終わりの画面を、HTML で組んで書き出す |

**分割画面：** C10、C18、C19 では、2 人の画面を並べる。VRChat の Build & Test で 2 つのクライアントを並べて録れば、実際に同期した画面になる。

### 2.2 登場人物

| 人物 | 役 | 絵での描き方 |
| --- | --- | --- |
| MAO | 主役。KawaPlayer を置いたワールドで、プレイヤーを動かす人。インスタンスを作った人で、ライブを観る会の主催 | 青緑のシルエット |
| RIRIKA | 友だち。あとから入ってくる | ピンクのシルエット、ツインテール |

- **アバター：** どちらも購入したアバターで、利用規約で映像作品への利用が認められている。クレジットは、作者の指定どおりに終わりの画面へ入れる。
- **リポジトリに置かないもの：** 利用規約が再配布を認めていないため、アバターのデータは置かない。アバターが映った絵や、撮った映像の静止画も置かない。動画のファイルも GitHub には上げない。

### 2.3 舞台

- **場所：** 夜の部屋 1 つで通す。C17（次の日）だけは昼にする。ライブを観る会（C18・C19）も同じ部屋で撮る。
- **部屋のシーン：** テスト用のプロジェクトにある、購入した部屋の素材を使う。映像に出してよいかは、撮影の前に規約で確かめる。

### 2.4 画面に映すもの

- **動画・画像・配信：** スクリーンに映す動画、画像、ライブ配信は、この動画のために作ったサンプルにする。実在の曲、番組、配信は映さない。
- **VHub のプレイリスト：** 撮影のために作ったサンプルを使い、撮影のあとで消す（使い方ガイドの写真と同じやり方）。
- **名前：** 訪問者アプリの名前なども、サンプルにする。
- **音：** スクリーンの映像の音は使わず、BGM と効果音だけにする。

### 2.5 文字と色

- **文字：** Zen Maru Gothic（パッケージに入っている文字）。
- **章の見出し：** 左下に出す。中身は、番号、機能の名前、一言、英語の一行。
- **テロップ：** 下の中央に出す。
- **吹き出し：** 漫画の形にする。
- **色：** ロゴの 3 色（#6bebaa・#3fc4c6・#22a6cb）を使う。

### 2.6 絵について

- **仮の絵：** [4 章](#4-絵コンテ)の絵は仮のもので、[`images/frames.py`](images/frames.py) が描く。
- **人物：** シルエットで描く。
- **KawaPlayer の画面：** 使い方ガイドの写真から切り出す。
- **オレンジの注記：** 枠・矢印と右上の札は、カメラの動きと演出のメモで、動画には出ない。
- **文字：** 見出し、テロップ、吹き出しは、動画に出る位置に描いた。
- **差し替えない：** issue では、HTML の構成ができたら絵をその瞬間の書き出しに差し替える予定だった。書き出しにはアバターが映るので、リポジトリの絵は仮の絵のままにする。書き出しとの見比べは、手元で行う。

## 5. 決めること

1. **キャッチコピー（C22）：** 次の案から選ぶか、ほかの言葉にする。
   - 同じ映像を、同じ瞬間に。
   - みんなで観る時間を、もっと近くに。
   - URL ひとつで、みんなの上映会。
2. **英語の一行：** 見出しとテロップに英語を添えるか。添えると、海外のワールド制作者にも伝わる。そのぶん、画面の文字は増える。絵では添えた。
3. **BGM：** 権利のはっきりしたもの。商用で使えることと、YouTube の Content ID で止められないことを確かめる。
4. **撮影する部屋：** テスト用のプロジェクトの部屋で撮るか（[2.3](#23-舞台)）。
5. **縦長の短い版：** 横長の版ができてから決める。

## 6. 次にやること

1. **レビュー：** この絵コンテを PR でレビューし、[5 章](#5-決めること)を決める。
2. **撮影リスト：** 〔Unity〕のカットから、撮影のリストをつくる。中身は、アバターの置き方と動き、カメラ、KawaPlayer の状態、必要なアセット。
   - **アセット：** AudioLink、Unity Recorder。どちらも一時的に入れて、撮り終えたら外す。
3. **HyperFrames の構成：** リポジトリの外（`D:\Codes\videos\`）に作業のフォルダーをつくり、題名・見出し・テロップ・分割・終わりの画面を組む。
4. **確かめる：** 決めた瞬間を静止画に書き出し、この絵コンテと手元で見比べる。
