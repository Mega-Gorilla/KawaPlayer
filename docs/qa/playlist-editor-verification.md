## 手順

### 前提

- Unity Editor でテストプロジェクトを開いておく
- **Unity MCP** (`com.coplaydev.unity-mcp`) が動いていること
- yt-dlp が導入済みであること (ツールバーが「yt-dlpをダウンロードする」ではなく「yt-dlpを更新する」になっていれば導入済み)
- VHub の共有 URL が 2 本。**取り込み済みのものと未取り込みのものの両方**が要る

### 原則

- **シーンを保存しない。**Playlist Editor の Save はシーン上のコンポーネントを書き換えるが、シーンファイル自体は保存しなければ無傷のまま
- 終了時に `EditorSceneManager.OpenScene(path, Single)` で読み直して破棄し、**開始前のバックアップと MD5 を突き合わせる**
- 検証中に変更したエディタ言語などは元に戻す

### Editor を自動操作する

GUI を人手で触る代わりに、Win32 メッセージで EditorWindow を直接操作できる。**カーソルもフォーカスも奪わない**ので、操作中に他の作業を邪魔しない。

| やること | 方法 |
| --- | --- |
| **状態を読む** | Unity MCP の `execute_code` でリフレクション。`_playlists` / `_selectedPlaylist` / `_playlistsTable.index` / `selectedIndices` / `_playlistTracksTable.list` を JSON でファイルへ書き出す |
| **クリック** | ウィンドウ配下の `UnityGUIViewWndClass` へ `WM_MOUSEMOVE` → `WM_LBUTTONDOWN` → `WM_LBUTTONUP` を `PostMessage` |
| **文字入力** | 同じ子ウィンドウへ `WM_CHAR`。消去は `VK_END` のあと `VK_BACK` を必要数 |
| **ダイアログ** | `EditorUtility.DisplayDialog` も進捗バーもファイル選択も **すべて Win32 の `#32770`**。子の `Button` からラベルを読み取り、狙ったものに `BM_CLICK` を送る。**ラベルを読めるので「どのダイアログが出たか」自体が証拠になる** |
| **ファイル選択** | 最初の `Edit` にフルパスを `WM_SETTEXT` し、`保存(&S)` / `開く(&O)` を `BM_CLICK` |
| **画面の確認** | ウィンドウを最前面に上げて全画面をキャプチャし、ウィンドウ矩形で切り出す |

### 踏みやすい落とし穴

1. **モーダル中は MCP 呼び出しが `success:false` で即座に返る。**コードは動き続けているだけで、失敗ではない。**戻り値に頼らず結果をファイルへ書く**こと
2. **posted click はモーダルの間キューに溜まり、閉じた後に配送される。**各操作のあとで**ダイアログを吸い出し、`_importInFlight` が下りるまで待つ**こと。これを怠ると同じ取得が何度も走る
3. **IMGUI の TextField は内部に編集バッファを持つ。**BackSpace が古いバッファに効いて前回値が混ざることがある。**入力後に必ずモデル側を読み戻して照合し、違えばやり直す**
4. **画面 DPI が 100% でない環境では座標がずれる。**`GetWindowRect` は論理座標を返すのに `CopyFromScreen` は物理ピクセルで動くため、PowerShell 側で `SetProcessDPIAware()` を呼ぶ
5. **端末ウィンドウに Z オーダーを奪われる。**Unity ウィンドウを空いているモニタへ退避させてから撮ると安定する
6. **`ReorderableList` は生成直後、`index` が末尾を指していても `selectedIndices` は空。**「index が合っているから選択されている」と判断してはいけない (#106 参照)

### 何を証拠として残すか

- **数える** — 曲数・件数・`index`・`selectedIndices`
- **突き合わせる** — 取り込んだトラック列を**取得元 (VHub の応答 / 書き出した JSON) と全件比較**する。ハッシュを取ると差分の有無が一目で分かる
- **文言を読む** — ダイアログのタイトルとボタンのラベルをそのまま記録する
- **Console を見る** — 各操作の前に消し、後で読む。**「何も出ない」ことも証拠**になる (J-1d の「yt-dlp が起動していない」はこれで示した)
