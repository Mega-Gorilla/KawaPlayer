# KawaPlayer のロゴ

KawaPlayer のロゴの 3 種類を保管しています（issue #189）。

| ファイル | 色 |
| --- | --- |
| `kawaplayer-logo-white.png` | 白 |
| `kawaplayer-logo-black.png` | 黒 |
| `kawaplayer-logo-gradient.png` | 緑から青へのグラデーション |

- **大きさ:** もとは 8192 × 8192 です。ここでは 1024 × 1024 に縮めています。
- **直したところ:** ロゴから離れた場所に、編集のときの薄い消し残しがありました（不透明度 1〜12%）。それを透明にしています。ロゴの形は変えていません。
- **Unity との関係:** フォルダー名が `~` で終わるので、Unity はこのフォルダーを読み込みません。プロジェクトにもワールドにも入りません。
- **KawaPlayer が使うもの:** KawaPlayer が使うのは、白と同じ画像の `../kawaplayer-logo.png` だけです。色は使う側で付けます（待ち受け画像では白、タブレットの裏では濃い青）。
